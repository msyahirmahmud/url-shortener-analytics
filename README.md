> High-performance URL Shortener & Click Tracking Service built with Python and FastAPI.

---

## 🌟 Features

- **⚡ Fast Hashing**: Generates unique 6-character MD5 hash codes.
- **📊 Analytics & Click Tracking**: Tracks total redirection clicks and creation timestamps.
- **🛡️ URL Format Validation**: Enforces valid `http://` or `https://` protocols.

---

## 🚀 Quick Start

```bash
git clone https://github.com/msyahirmahmud/url-shortener-analytics.git
cd url-shortener-analytics
python3 main.py
```

Run test suite:
```bash
python3 -m unittest discover tests
```
